8. OBSERVACIONES DE DISEÑO
================================================================================

  1. PALETA COHESIVA WARM: Toda la app usa una gama cálida naranja/marrón
     (hue 22-30). El fondo de página es naranja cálido (#ea8e5a), haciendo
     que las tarjetas blancas "floten" encima.

  2. PATRÓN DE SELECCIÓN CONSISTENTE: Todos los elementos seleccionables
     (categorías, sabores, tamaños, boba, toppings) usan el mismo patrón:
     rounded-xl border p-4 → selected: border-primary bg-primary text-
     primary-foreground / unselected: border-border bg-card, con
     hover:shadow-md y transition-all.

  3. BOTONES DE ACCIÓN CON COLORES CUSTOM: El store sobrescribe colores
     de Button extensamente con utilidades Tailwind: verde para
     siguiente/confirmar, púrpura para retroceder, naranja para "armar
     otra bebida", blanco sobre naranja para el CTA principal.

  4. PWA MÓBILE-FIRST: Viewport bloqueado (sin zoom), display standalone,
     orientación landscape, service worker con caché agresivo, font stack
     del sistema para performance.

  5. SIN ANIMACIONES EN TRANSICIÓN DE PÁGINAS: La navegación entre páginas
     usa Next.js estándar. Las animaciones internas son limitadas:
     crossfade del carrusel (700ms), apertura de dialog (200ms zoom+fade),
     y transiciones de hover con sombra.

  6. TIPOGRAFÍA MÍNIMA: Solo fuentes del sistema. El preview-theme.html
     referencia Inter pero la app real NO la importa.

  7. ESCALA DE ESPACIADO: Sigue los defaults de Tailwind:
     gap-1/2/3/4/6/8, p-2/3/4/6/10, px-4, py-3, space-y-1/2/3/4/6/8.

  8. CONTRASTE: El fondo naranja (#ea8e5a) con texto marrón oscuro
     (#692400) puede tener problemas de contraste WCAG depending on
     the specific combination. Las tarjetas blancas con texto marrón
     oscuro tienen buen contraste.

  9. PATRÓN DE GRADIENTES: Header usa gradiente horizontal
     (from-primary to-accent). Hero usa gradiente diagonal
     (from-primary via-accent to-orange-300). Ambos con sombra
     naranja difusa.

 10. TAMAÑOS DE BOTONES PEQUEÑOS: Los botones de acción del carrito
     (w-36 h-7 = 144px × 28px) son significativamente más pequeños
     que el estándar de botones (h-9 = 36px). Esto podría afectar
     la usabilidad táctil en móviles.
