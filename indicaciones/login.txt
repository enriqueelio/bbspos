Modifica el sistema de autenticación en todo el monorepo para usar un "Nombre de Usuario" (username) en lugar de un correo electrónico, agilizando el acceso del personal en el punto de venta.

**1. Actualización de Base de Datos (Prisma)**
Abre `packages/db/prisma/schema.prisma`.
- En el modelo `User`, reemplaza el campo `email String @unique` por `username String @unique`.
- (Opcional si necesitas mantener el correo para el admin: añade `username String @unique` y haz que `email` sea opcional `email String? @unique`).
- Actualiza el archivo `packages/db/prisma/seed.ts` para que los usuarios por defecto usen credenciales rápidas (ej. `username: "admin"` y `username: "cajero"`).
- Al finalizar, recuérdame ejecutar `pnpm db:migrate` para aplicar los cambios a SQLite.

**2. Lógica de Autenticación (NextAuth)**
Abre `apps/cajero/lib/auth.ts` y `apps/admin/lib/auth.ts`.
- En el `CredentialsProvider`, cambia la configuración de `credentials` para solicitar `username` en lugar de `email`.
- En la función `authorize(credentials)`, actualiza la consulta de Prisma a: `prisma.user.findUnique({ where: { username: credentials.username.toLowerCase() } })`.

**3. Interfaz de Login (UI)**
Abre `apps/cajero/app/login/login-form.tsx` y `apps/admin/app/login/login-form.tsx`.
- Modifica el campo de entrada: cambia `type="email"` a `type="text"`.
- Cambia los atributos `name` e `id` de "email" a "username".
- Actualiza las etiquetas (Labels) y placeholders visuales de "Correo electrónico" a "Usuario" (ej. placeholder "cajero_turno1").

**4. Panel de Administración (Gestión de Usuarios)**
Abre `apps/admin/actions/users.ts` y `apps/admin/app/(dashboard)/users/users-client.tsx`.
- Modifica las validaciones de Zod o del servidor: elimina la validación de formato `.email()` y reemplázala por una validación alfanumérica simple para el `username`.
- Actualiza la tabla de usuarios en la UI para que la columna muestre el "Usuario" en lugar del correo.
