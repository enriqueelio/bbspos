Vamos a crear la interfaz de usuario para que el cajero arme pedidos a alta velocidad.

**1. Estado del Carrito Local**
Crea `apps/cajero/components/pos/pos-cart-store.ts` usando Zustand (o un Contexto de React) para manejar un array de `cartItems`, un campo para `customerName` y un `deliveryType` (MESA/LLEVAR).

**2. Layout del Punto de Venta**
Crea `apps/cajero/components/pos/pos-terminal.tsx`. Este será un Client Component.
Usa un layout de pantalla dividida:
- **Izquierda (70%):** Un grid con pestañas (Tabs) para Categorías (Milk, Water, Special). Al seleccionar una categoría, muestra los sabores como botones grandes (`h-16 text-lg`). Debajo, selectores rápidos para Tamaño y Tipo de Boba (basado en el catálogo que pasaremos por props).
- **Derecha (30%):** El "Ticket en Curso". Una barra lateral fija con fondo `bg-slate-900`. Debe listar los ítems agregados (usando un diseño compacto), un input para el nombre del cliente, un toggle MESA/LLEVAR, y un botón gigante en la parte inferior "Enviar y Cobrar (Total: X Bs)" con `bg-primary text-white h-20 text-xl font-bold`.
